3 ระยะการสุกที่โมเดลเรียนรู้

โมเดลฝึกจากภาพกล้วยหอมจริง 300 ภาพ แบ่งเป็น 3 คลาส คลาสละ 100 ภาพ โดยสกัดคุณลักษณะจากโทนสีและพื้นผิวของเปลือก

ระยะดิบห่าม
เปลือกสีเขียวถึงเขียวอมเหลือง เนื้อด้านในยังแข็ง ยังไม่พร้อมรับประทาน
เก็บที่อุณหภูมิห้อง ห่อขั้วด้วยพลาสติกเพื่อชะลอการสุก
ระยะสุกกำลังดี
เปลือกสีเหลืองนวลทั่วผล เนื้อนุ่มหวาน พร้อมรับประทานทันที
แขวนไว้ให้ผลไม่ทับกัน หรือแช่เย็นเพื่อชะลอการสุกต่อ
ระยะสุกงอมเริ่มเสีย
มีจุดสีน้ำตาลกระจายทั่วผลหรือเปลือกคล้ำดำ เนื้อเริ่มนิ่มมาก
ปอกเปลือกแช่แข็งเก็บไว้ หรือนำไปแปรรูปเป็นเค้กกล้วยหอมลดขยะอาหาร
วิธีทำงานของระบบ

จากภาพถ่ายสู่คำแนะนำ ใน 4 ขั้นตอน

01

เปิดกล้อง

เบราว์เซอร์เข้าถึงกล้องของอุปกรณ์และสตรีมภาพสดขึ้นหน้าเว็บแบบเรียลไทม์

02

จับภาพและวิเคราะห์

ระบบอ่านค่าโทนสีและพื้นผิวของเปลือกกล้วยจากเฟรมภาพที่จับได้

03

จำแนกระยะ

เทียบคุณลักษณะที่สกัดได้กับรูปแบบของ 3 ระยะ พร้อมคำนวณค่าความเชื่อมั่น

04

แสดงคำแนะนำ

ระบบแนะนำวิธีเก็บรักษาหรือแปรรูปที่เหมาะกับระยะที่ตรวจพบทันที

เบื้องหลังโมเดล

ต้นแบบของโครงงานฝึกโมเดลจำแนกภาพผ่านแพลตฟอร์มไร้โค้ด แล้วส่งออกเป็นไฟล์สำหรับประมวลผลฝั่งไคลเอนต์ เพื่อให้เว็บไซต์นี้ทำงานได้ทันทีในเบราว์เซอร์โดยไม่ต้องส่งภาพขึ้นเซิร์ฟเวอร์

HTML / CSS / JavaScript ประมวลผลฝั่งไคลเอนต์ วิเคราะห์โทนสีเปลือก

เครื่องมือคัดแยกต้นทุนต่ำ เพื่อผู้บริโภคและร้านค้าปลีก

ออกแบบมาให้ผู้บริโภคทั่วไปและร้านขายผลไม้ขนาดเล็กใช้คัดแยกคุณภาพกล้วยหอมได้อย่างเป็นมาตรฐาน ลดการคาดเดาด้วยสายตา และช่วยวางแผนการเก็บรักษาหรือแปรรูปก่อนกล้วยเสีย ซึ่งเป็นแนวทางหนึ่งในการลดปริมาณขยะอาหารจากผลไม้ที่สุกงอมเกินไป

ผลการทดลองใช้งานกับกลุ่มตัวอย่างผู้บริโภคและผู้ประกอบการร้านค้าปลีกพบว่าเว็บไซต์ใช้งานสะดวก รวดเร็ว และได้รับความพึงพอใจในภาพรวมอยู่ในระดับดีเยี่ยม
